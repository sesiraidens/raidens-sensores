## Sobre

Modulos de leitura e processamento para sensores comuns: ultrassonico, infravermelho, cor, giroscopio e magnetometro.

---

## Sensores

| Sensor | Protocolo | Alcance |
|---|---|---|
| HC-SR04 | Digital | 2-400cm |
| TCRT5000 | Digital/Analogico | 1-3mm |
| TCS3200 | Digital (frequencia) | - |
| TCS34725 | I2C | - |
| MPU6050 | I2C | 6 eixos |
| HMC5883L | I2C | Magnetico |
